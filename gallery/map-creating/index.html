地圖創作

  • 創作
  • MAP-CREATING

時間：2024 年年末—2025 年一月底

當時同時對 Minecraft Create 模組與鐵路文化異常有熱情。一直想要在 Minecraft 的世界裡建構一個鐵路系統，而且自然景觀、城市風貌全部都要有。而且我還不滿足要蓋一條線路，打從一開始就想要規劃很多條線（轉乘是一大重點）。於是這麼貪心的我，從地圖開始為腦海中的虛構城市描繪外貌。

不過隨著城市需要填充的細節越來越多，我在某一個瞬間失去了耐心，便放著不管了。

劃完行政區之後劃縣市，結果畫出來「氾里市」的市界長得像是一個展翅的鳥人。

為了方便在 Minecraft 建造（尤其要考量到 Create 鐵軌只能直角/45度放置），也在格線紙上畫地圖。

在構思地圖的時候，參考了諸多台北實際存在的鐵路特徵： - 紫線接「南埔機場」，很明顯是在參考桃園機場捷運。 - 紫、橘、淺藍線在「宜河區」東側有三角轉乘，參考北捷的東門—南門—古亭。 - 靠「南埔區」的「亙中溪」左岸有緊貼著河岸的紫線一站，參考機捷三重站。 - 西南角淺藍、橘線平行，參考台北市東側綠、藍、紅線平行排列。

我還哇到了當時（2024/11）做的「願望清單」：

為線路標號＆取名。鐵路單位的名稱叫做「省鐵」。

這是為了參考而按照我自己的規則描邊的台北市區地圖。淺綠色是河岸、深綠色是市區邊界。為了避免看起來太熟悉，我還刻意把地圖擺「歪」的，讓圖中的正北朝著右下。

除了捷運以外，也特意將鐵路車站標示出來。橘色是等高線。
